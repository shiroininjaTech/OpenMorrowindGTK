OpenMWind Cinnamon v7 — Gilded Title Bars

Based on v6. Recolors the existing weathered-bronze PNG into aged sandstone gold in both GTK assets and Metacity, preserving its engraved details. GTK title-bar text is darkened for contrast. The Cinnamon panel remains dark bronze using panel-patina.png.

Install: extract OpenMWind-Cinnamon-v7 into ~/.themes/. In Cinnamon Themes select v7 for Applications and Window borders. Keep Desktop on v6 to preserve your existing panel (or select v7 Desktop for the equivalent panel). If decorations do not refresh, toggle to another theme and back.

Keep v6 installed for rollback. No Bethesda assets included.
