OpenMWind Icons v3 — original fantasy-inspired SVGs.

Install folder in ~/.local/share/icons/ and select OpenMWind Icons v3 in Cinnamon Themes > Icons.
Adds illustrated books, scrolls, chests, gears, hourglasses, and common file aliases. Existing app logos fall back to Papirus-Dark/Adwaita for recognizability.

This package does not contain Bethesda game assets.
